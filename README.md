# Studio previews

Personal preview pages for PMU studio outreach (demo mode, nothing is saved).

- Studio page: `/s/preview?studio=Glow%20Brows&artist=Jess&city=Bakersfield&rating=4.9&reviews=87`
- Dashboard: `/dashboard?studio=Glow%20Brows&artist=Jess`

Built from the studio-funnel app (`sh .check/build.sh`, then copy `.check/dist`). `404.html` is a copy of `index.html` so every path opens the app.
